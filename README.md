# The Worst App Idea Ever Pitched — entry

A program/v1 entry for the make.fun "The Worst App Idea Ever
Pitched" bounty. `main.py` writes one pitch sentence to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The pitch:

> Meet Queue: wait in a virtual line to be told the thing you queued for is available instantly elsewhere; the Pro tier waits longer.

Disrupting patience itself. See `CANDIDATES.md` for the full
draft list this winner was picked from.
